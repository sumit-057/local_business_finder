## What to build

A "Near Me" action requests geolocation only when chosen, then runs an Overpass radius search for the active Category around the visitor's position, rendered through the same Place pipeline into the existing list (and map once the map ticket lands). Denied or unavailable permission falls back to a designed state suggesting a manual Smart Query instead - never a dead end.

## Acceptance criteria

- [ ] Near Me returns nearby Places for the active category
- [ ] Permission denial or unavailability shows a graceful fallback state
- [ ] Radius route handler covered by seam tests (query built correctly, Place shape out)
