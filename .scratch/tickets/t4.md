## What to build

Selecting a Place opens a detail slide-over over the split view on desktop and a full-screen sheet on mobile, at its own URL (/place/[osmType]/[id]) so details are shareable and back-navigation preserves list/map context. An enrichment route handler queries Overpass for the selected Place; phone, website, and opening-hours sections render only when volunteers have tagged them - never nulls. The view includes address, coordinates, a static map preview, and a directions link. Handler seam tested for enrichment shape and omission of untagged fields.

## Acceptance criteria

- [ ] Slide-over opens from a card or pin; direct URL load works; back returns to context
- [ ] Enrichment sections appear only when data exists
- [ ] Static map preview and directions link present
- [ ] Handler tests cover enrichment shape and conditional omission
