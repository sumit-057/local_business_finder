## What to build

Cmd/Ctrl+K opens a centered command palette wrapping the exact same Smart Query flow as the main search box, with recent searches and category chips usable inline. It adds no new data flow - purely a faster doorway into existing behavior.

## Acceptance criteria

- [ ] Palette opens/closes via keyboard; focus is trapped sensibly while open
- [ ] Submitting from the palette behaves identically to main search
- [ ] Recent searches and category chips are selectable inside the palette
