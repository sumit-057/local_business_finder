## What to build

The product exists as a running Next.js App Router + TypeScript app already wearing its visual identity: dark premium theme with one restrained accent, brand bar with custom SVG logomark, gradient-mesh plus noise background layers, base typography scale, shadcn/ui wired up, Framer Motion available. The layout shell renders the regions the app will fill (search area, results region, map region) responsively. Deploys green on Vercel. The visual kit is isolated so art assets stay easily replaceable.

## Acceptance criteria

- [ ] Brand bar, logomark, background layers, typography scale in place
- [ ] Layout shell renders search/results/map regions on desktop and mobile widths
- [ ] Lint and typecheck pass
