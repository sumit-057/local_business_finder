## What to build

Results appear simultaneously on a free-tile react-leaflet map beside the card list: one pin per Place, hovering a card highlights its pin and vice versa, selection stays consistent across both. Desktop is a split view; mobile gets a list/map toggle so each pane takes the full screen.

## Acceptance criteria

- [ ] Pins render for every result and update when the search changes
- [ ] Hover sync works in both directions (card to pin, pin to card)
- [ ] Desktop split view; mobile toggle switches full-screen panes
